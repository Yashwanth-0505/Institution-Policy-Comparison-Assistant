What POLICYX does

Every clause. Every change. Explained.

Semantic Clause Alignment

TF-IDF baseline combined with sentence embeddings to align clauses even when headings or numbering change.

Substantive vs Wording

Detects numeric changes, negation flips, obligation shifts, and added/removed clauses separately from minor wording edits.

Citation Validation

Every detected change is cited back to the exact page and clause in the source PDF, so the result is always traceable.

LLM Bounded Summaries

Language model generates concise explanations of each change — grounded only in the actual clause text, never hallucinated.

Investigation Mode

Only have the newer policy? POLICYX can search authoritative sources to locate the previous version and verify its provenance.

Local ML Pipeline

Runs entirely on your machine. No data is sent to external servers. 66 unit tests covering every detection scenario.
